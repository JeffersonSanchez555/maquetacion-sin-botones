¿Qué es el Machine Learning?

Es una rama de la IA que permite a los sistemas aprender y mejorar automáticamente a partir de los datos sin ser programados explícitamente.

Pandas

Biblioteca de Python diseñada para el análisis y manipulación de datos estructurados.

NumPy

Librería fundamental para el cálculo científico y manejo de arreglos multidimensionales.

PyTorch

Framework de aprendizaje profundo utilizado para construir redes neuronales complejas.

Jupyter

Entorno interactivo ideal para crear, ejecutar y compartir código de análisis de datos.

Lenguaje R

Lenguaje especializado en computación estadística y gráficos para el análisis masivo de datos.

Docker (MLOps)

Herramienta para empaquetar y desplegar modelos de IA en entornos de producción estables.

Visión por Computadora

Tecnología que permite a las computadoras extraer información a partir de imágenes o videos.
